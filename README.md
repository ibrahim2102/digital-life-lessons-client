
# Digital Life Lessons

**Life Lessons** is a community-driven web platform where users can share real-life experiences, insights, and lessons to inspire and help others grow personally and emotionally.

 **Live Website(Client): https://digital-life-lessons-140b5.web.app
**Live Website(Server): https://digital-life-lessons-server-virid.vercel.app
---

## Features

● Users can create and publish personal life lessons with detailed stories
● Firebase Authentication for secure login and user management
● Image upload support for lessons using a third-party image hosting service
● Premium and free access control for lesson visibility
● Fully responsive design for mobile, tablet, and desktop devices
● Fast and smooth UI built with React and modern frontend tools
